# 录影提词机 WebApp

这个项目是一个纯前端 WebApp，整合了：

- 录影（摄影机 + 麦克风，导出 WebM）
- 提词机（大字号滚动稿件）
- 语音转文字跟随（讲到哪就跳到哪）
- 文字转语音预览（TTS）

## 本地运行

```bash
cd /Users/chenguanyu/Documents/提詞機
python3 -m http.server 8080
```

然后打开：

`http://localhost:8080`

## 使用流程

1. 点击「开启设备」并允许摄影机/麦克风权限。
2. 在「提词稿」贴上你的稿件（建议一行一句）。
3. 点击「加载提词稿」。
4. 点击「开始语音跟随」，开始讲话，系统会自动高亮当前行。
5. 点击「开啟全螢幕题词」，进入沉浸模式：背景是全螢幕相机画面，题词是完整滚动稿件。
6. 全螢幕上方可直接按「开始录影 / 停止录影」，并可切换「语音跟随：开/关」。
7. 全螢幕可切换「镜像画面：开/关」，把相机画面左右镜像。
8. 在全螢幕上方可用 `A- / A+` 或滑杆调整字体大小，提词会保持自动跟随滚动。
9. 语音跟随预设为开启，加载稿件并取得权限后会自动尝试跟随。
10. 全螢幕字幕在上方、控制列在最下方；当前句会平滑滚到显示区第一行，按 `↑ / ↓` 可切换上一句或下一句。

## 技术说明

- 录影：`MediaRecorder` + `getUserMedia`
- 语音识别：`SpeechRecognition` / `webkitSpeechRecognition`
- 文字转语音：`speechSynthesis`
- 输出格式：优先尝试 `MP4`，浏览器不支援时自动回退 `WebM`

## 浏览器建议

建议使用最新版 Chrome / Edge。Safari 与 Firefox 对语音识别支持较弱，可能无法使用「语音跟随」。
